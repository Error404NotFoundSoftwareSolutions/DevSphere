# User testing log

One entry per session. Newest first. Link each finding to a change.

| Date | Participants (count, level) | Task | What happened | What we changed | Status |
|---|---|---|---|---|---|
| (example) | 5 beginners | Complete the first lab | 3 of 5 missed the Submit button | Moved Submit into the result panel | Done |

## Template for a session

- **Goal:** (for example: can a beginner find the next action without help? NFR-UX-001)
- **Method:** moderated, think aloud, 30 minutes
- **Findings:** observations, not opinions
- **Changes:** story or issue links
