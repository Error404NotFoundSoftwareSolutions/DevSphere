# Backend API

OpenAPI is generated by the FastAPI app (`services/api`) and is the contract; the typed client in `packages/api-client` is generated from it. This page is the human summary.

Conventions: HTTPS only, JSON, URL-versioned (`/v1`). Bearer token on every protected call. State-changing calls accept `Idempotency-Key`. Errors: `{ code, message, recovery, correlation_id }`. Lists are paginated. Rate limits apply to sign-in related, tutor, submission and profile endpoints.

| Method and path | Purpose | Story |
|---|---|---|
| `GET /health` | Liveness | US-05 |
| `GET /v1/me` | User, role, consent state | US-01 |
| `PUT /v1/me/consent` | Record notice version and age-check outcome | US-02 |
| `GET, PUT /v1/me/profile` | Own profile | US-03 |
| `GET /v1/students/{id}/profile` | Read student profile (own or audited operator) | US-03 |
| `GET /v1/operator/students/{id}/profile` | Audited operator inspection of student profile | US-03, US-35 |
| `POST /v1/me/export-request`, `POST /v1/me/deletion-request` | Data requests | US-04 |
| `GET /v1/labs` | Catalogue | US-06 |
| `GET /v1/labs/{id}/versions/{v}/bundle` | Signed bundle URL | US-07 |
| `POST /v1/attempts` | Create attempt pinned to versions | US-08 |
| `POST /v1/attempts/{id}/events` | Batch progress events | US-22 |
| `GET /v1/attempts/{id}` | Attempt state and results | US-21 |
| `POST /v1/attempts/{id}/submissions` | Create submission, get upload URL | US-28 |
| `POST /v1/submissions/{id}/complete` | Confirm upload, enqueue grading | US-28 |
| `GET /v1/submissions/{id}` | Status and result | US-30 |
| `POST /v1/tutor/messages` | Tutor proxy (streamed) | US-25 |
| `POST /internal/grader/results` | Signed result from the Orchestrator (not public) | US-30 |
| `GET /v1/config` | Minimum client version, flags | US-05 |

Operator actions (role change, score correction, data export and deletion) use a separate router that requires the `operator` role and writes an audit event.
