## User story
As the team, student code runs only in a disposable sandbox with no network and no secrets, away from our data.

## Requirements covered
- [ ] `FR-GRADE-005`: The Grader shall run the snapshot against the pinned visible and protected tests in a disposable sandbox that is non-root, has no network by default, has CPU, memory, time, process and output limits, and has no access to secrets or application data.
- [ ] `FR-GRADE-006`: The Grader environment shall run in a project or environment separate from the application database and production secrets.
- [ ] `NFR-SEC-007`: The Grader sandbox shall isolate student code from the host, network, other submissions and platform secrets, and the isolation level shall be justified by the threat model (TBD-03).
- [ ] `NFR-SEC-008`: Protected tests, reference solutions and grader credentials shall exist only in grader-controlled storage and shall not be returned by any student-facing API.
