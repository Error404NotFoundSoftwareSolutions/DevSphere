## User story
As a student, I review a setup plan and consent before anything is installed, and nothing runs with permanent admin rights.

## Requirements covered
- [ ] `FR-ENV-004`: Before any change, the Client shall show a setup plan listing what will change, why, the source, expected download size, required permissions and any restart.
- [ ] `FR-ENV-005`: The Client shall obtain explicit consent before installing software, changing system settings or starting services, and shall make no such change if consent is withheld.
- [ ] `FR-ENV-006`: The Client shall not run persistently with administrator/root privileges and shall request elevation only for the single operation that needs it.
- [ ] `FR-ENV-011`: Downloads used for setup shall come from official sources and shall be verified by checksum or signature where the source provides one.
- [ ] `NFR-SEC-009`: The Client shall not run student code or setup tasks as administrator/root by default.
- [ ] `NFR-SEC-010`: Application updates and downloaded installers shall be verified by signature or checksum.
