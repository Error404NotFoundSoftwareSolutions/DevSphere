## User story
As a beginner, I can find the next action, use the keyboard, and understand every error.

## Requirements covered
- [ ] `NFR-UX-001`: In usability sessions with beginner participants, a majority shall be able to identify the next required action on the active lab screen without help (success threshold; TBD-14).
- [ ] `NFR-UX-002`: Setup instructions shall state what the tool is, why the lab needs it, what will change and how success is verified.
- [ ] `NFR-UX-003`: The Client shall use consistent status terms for ready, missing, installing, verifying, failed, passed and blocked.
- [ ] `NFR-UX-004`: Primary controls shall be reachable by keyboard with a visible focus indicator.
- [ ] `NFR-UX-005`: The Client shall aim for WCAG 2.2 AA principles where applicable, with deviations recorded.
- [ ] `NFR-UX-006`: Every error message shall state the problem and a recommended recovery action.
- [ ] `NFR-UX-007`: The student shall be able to request more detail or a higher assistance level from the tutor without restarting the lab, within the lab's maximum level.
