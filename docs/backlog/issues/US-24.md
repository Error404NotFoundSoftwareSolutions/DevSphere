## User story
As a student, the tutor explains and gives progressive help up to the lab's limit and never claims code is correct.

## Requirements covered
- [ ] `FR-AI-006`: The tutor shall offer progressive assistance (concept, hint, pseudocode, partial example, guided debugging, worked example) up to a per-lab maximum level that is set by the lab bundle and applied by the backend proxy; a level requested by the Client above that maximum shall be ignored.
- [ ] `FR-AI-007`: The tutor shall explain errors and give actionable guidance instead of only replacing code.
- [ ] `FR-AI-008`: The tutor shall label its output as suggestions and shall not state that code is correct or passing until a test confirms it.
- [ ] `FR-AI-016`: The tutor shall not execute commands or edit files without explicit student approval.
