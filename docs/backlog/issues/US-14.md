## User story

## Requirements covered
- [ ] `NFR-PORT-001`: Core MVP functions shall work across Windows, Linux and macOS.

- [ ] `NFR-PORT-003`: Lab manifests shall declare supported OS, architecture and tool-version constraints.
- [ ] `NFR-PORT-005`: Flutter desktop CI shall build and smoke-test on Windows, Linux and macOS.
