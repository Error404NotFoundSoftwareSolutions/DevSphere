## User story
As a student, I can see available labs with difficulty, prerequisites and supported systems.

## Requirements covered
- [ ] `FR-CAT-001`: The Client shall list published labs with title, description, difficulty, objectives, prerequisites, estimated effort, workspace type and supported operating systems.
- [ ] `FR-CAT-002`: Each lab shall be defined by a manifest conforming to a versioned schema, and the Client shall validate the manifest before using it.
- [ ] `FR-CAT-003`: The Client shall reject a manifest with an unsupported schema version and show a compatibility message instead of failing silently.
