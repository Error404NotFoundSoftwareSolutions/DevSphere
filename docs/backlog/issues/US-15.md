**Sprint:** 4  |  **Release:** MVP  |  **Priority:** P1 High  |  **Work order:** #23 of 60

## User story
As a student, I get a native editor, terminal and my guide side by side, chosen by the lab.

## Requirements covered
- [ ] `FR-WS-001`: The Client shall select the workspace from the lab manifest.
- [ ] `FR-WS-002`: The code workspace shall provide file navigation, editing, Python syntax support, an integrated terminal and execution of declared tasks.
- [ ] `FR-WS-003`: Workspace-specific code shall sit behind a documented, versioned interface so that further workspace types can be added without changes to the guide, tutor or grading logic.
- [ ] `FR-WS-004`: If a declared workspace type or dependency is unavailable, the Client shall show a recovery path and shall remain usable for other labs.
- [ ] `FR-WS-005`: The guide, tutor and results views shall remain available alongside the workspace.
- [ ] `NFR-MAINT-005`: Lab projects shall use standard repository and file formats in a documented, user-accessible directory so students can continue working outside the platform.
