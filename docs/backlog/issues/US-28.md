## User story
As a student, I review which files are sent, exclude secrets, and upload a snapshot for grading.

## Requirements covered
- [ ] `FR-GRADE-003`: The student shall be able to submit a snapshot for verified grading, and the Client shall label the returned result Verified.
- [ ] `FR-GRADE-004`: Before upload, the Client shall show which files will be submitted, exclude ignored and secret-bearing paths (including `.env` files) by default, enforce size and file-type limits, and obtain student confirmation.
- [ ] `NFR-SEC-014`: Archive and file handling in the Client, API and Grader shall prevent path traversal, symbolic-link escape and decompression bombs.
