## User story
As the team, backups are restored in a rehearsal, outages show clear messages, and bad content can be reversed.

## Requirements covered
- [ ] `NFR-REL-005`: Automated backups of the application database shall be enabled and a restore shall be tested before the pilot.
- [ ] `NFR-REL-006`: The backend shall return clear degraded-mode responses when identity, database, storage or queue dependencies are unavailable.
- [ ] `NFR-REL-007`: Material changes to published bundles shall be reversible by publishing an earlier content version (FR-CONT-007).
