## User story
As a student, I can set my name and optional college details, and only I can see them.

## Requirements covered
- [ ] `FR-PROF-002`: On first sign-in the Client shall collect a display name (prefilled from the identity provider and editable); all other profile fields shall be optional.
- [ ] `FR-PROF-003`: The profile shall support optional college/university, course, academic year/semester and interests; no date of birth, phone number or address shall be collected.
- [ ] `FR-PROF-004`: The backend shall validate profile fields (type, length, allowed characters) and reject invalid input with field-level messages.
- [ ] `FR-PROF-005`: The profile shall be created and updated for the user ID derived from the authenticated token; a user ID in a request body shall be ignored.
- [ ] `FR-PROF-006`: A student shall be able to read only their own profile and records; operator access shall require the `operator` role and shall be audited.
- [ ] `FR-PROF-007`: Profile data shall be private by default and shall not be visible to other students.
- [ ] `FR-PROF-008`: A student shall be able to view and edit their profile after onboarding.
