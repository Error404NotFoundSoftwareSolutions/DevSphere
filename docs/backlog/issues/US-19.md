## User story
As a student, I follow ordered steps with copyable snippets and explanations, and can revisit completed steps.

## Requirements covered
- [ ] `FR-GUIDE-001`: A lab shall present ordered, structured guide steps.
- [ ] `FR-GUIDE-002`: A step shall support explanatory text, instructions, code snippets, commands, file paths, expected output and references.
- [ ] `FR-GUIDE-003`: The Client shall provide a copy action that places exactly the snippet text, with original whitespace and without interface labels, on the clipboard.
- [ ] `FR-GUIDE-004`: Code examples shall be accompanied by explanations of the important sections.
- [ ] `FR-GUIDE-005`: The Client shall track guide-step completion independently of code correctness and environment readiness.
- [ ] `FR-GUIDE-007`: The student shall be able to revisit completed steps.
