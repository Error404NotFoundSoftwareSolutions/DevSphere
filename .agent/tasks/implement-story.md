# Task: Implement a user story

1. Read `docs/backlog/STORY_MAP.md` for the story and open every listed file.
2. Each file's header comment says which requirements it covers. Replace the starter code, keep the header.
3. Add tests first, named `TC-<requirement ID>-<nn>`.
4. Follow `WORKFLOW.md` steps 5 to 10.
Do not change files outside the story's list without saying why in the PR.
