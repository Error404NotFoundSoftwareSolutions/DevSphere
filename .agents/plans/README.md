# Plans

A plan turns an accepted decision into ordered, verifiable work. Plans are documents, not code. A plan whose status is `Proposed` must not be implemented (DOC-05).

| File | Track | Status |
|---|---|---|
| `00-master-plan.md` | all | Draft: phases, gates, dependencies |
| `10-agentic-kit-adoption.md` | X | Active: how the kit is introduced and verified |
| `20-ide-fork-plan.md` | B | Accepted (not yet Active) |
| `30-integrated-browser-plan.md` | C | Accepted (not yet Active) |
| `40-agent-runtime-plan.md` | D | Accepted (not yet Active) |
| `60-curriculum-and-roadmap-plan.md` | E | Proposed |
| `50-extensibility-plan.md` | X | Active (docs and registries first) |
| `plan-template.md` | - | Copy for new plans |

Milestone IDs use `PL-<track>-nn` (for example `PL-IDE-03`). They are promoted into `docs/backlog/` as stories only when the track is Accepted and the SRS is updated.
