# Task: triage an idea

1. Read the line in `ideas/INBOX.md`.
2. Score with `ideas/rubric.md`; note red flags.
3. Find or propose capability and extension points in `registry/`.
4. List needed answers as `Q-xxx` in `QUESTIONS.md`.
5. Update `ideas/BOARD.md`. Do not build. If it is promising, offer to draft an RFC (`templates/rfc.md`).
