# Task: record a decision

1. Check `docs/DECISIONS.md` for an existing ADR on the topic. Accepted ADRs are superseded, never edited.
2. Use `templates/adr.md`. Next number = highest + 1.
3. Include options considered, with the reason each was rejected.
4. Status `Proposed` until the owner says yes in chat; then `Accepted` with the date, and update `STATE.yaml` track status.
5. Update affected docs (`ARCHITECTURE.md`, `TECH_STACK.md`) in the same change.
