# New dependency checklist

- [ ] A story needs it; platform feature considered first.
- [ ] Licence is on the allowed list (DEP-02) or the owner approved.
- [ ] Maintained: recent release, active issues, more than one maintainer.
- [ ] Size/transitive deps reviewed; install scripts reviewed.
- [ ] Known advisories checked.
- [ ] Pinned and lockfile updated.
- [ ] Row added to `docs/TECH_STACK.md` (and `THIRD_PARTY_NOTICES` if vendored).
- [ ] Behind a port if it is an external service or engine (ARC-02).
