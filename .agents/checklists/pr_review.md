# PR review checklist

- [ ] Scope equals the story/milestone; no unrelated files.
- [ ] Rules by family reviewed: SEC TRU ARC STY TST DOC GIT AIR DEP (FRK).
- [ ] Tests exist, are named, include negative cases; results pasted.
- [ ] Contracts and docs updated together.
- [ ] Capability/extension-point registry updated if a feature or point was added.
- [ ] No secrets, protected content, IDE folders, build output.
- [ ] Risks and rollback stated.
- [ ] Reviewer is not the author (or labelled self-review).
