DevPilot is a desktop app and a VS Code guide. You tell it what you want to learn, or paste a job description, and it builds a step-by-step path. Each step has an explanation, a video you watch inside the app, a quick check and a hands-on lab. Labs open in **your own VS Code** and are checked by automated tests on **your own computer**. A tutor gives hints, never the finished answer.

:::note Preview
This is the first public preview (0.1.0). It runs on Linux and Windows. macOS is not available yet. Where something is planned and not built, these docs say so.
:::

## The idea in one picture

![A learning path in DevPilot](/app/paths.webp)

1. **Plan:** say what you want to learn.
2. **Watch:** videos play inside the app, and watching is measured.
3. **Practise:** the lab opens in your own VS Code.
4. **Check:** automated tests run on your computer.
5. **Prove:** finish a lab and claim a credential that says how it was checked.
