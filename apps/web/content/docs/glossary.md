title: "Glossary"
description: "The words DevPilot uses, in plain language."
section: Reference
order: 7
---

| Term | Meaning |
|---|---|
| **Check** | An automated test run on a lab step. It decides pass or fail. |
| **Coach** | The AI helper that explains errors and reviews code as advice. Never changes a score. |
| **Completed** | The credential level for a lab whose checks passed on your own computer. Labelled *checked on your computer*. |
| **Credential** | A record that you finished a lab, with the skills it covered and how it was checked. |
| **DevPilot Guide** | The VS Code extension that shows a lab's steps and runs checks. |
| **Gemini** | Google's AI models, used by the DevPilot service. |
| **Helper (worker)** | The program next to the app that touches your files, starts VS Code and runs checks. |
| **Hint level** | How much help the tutor may give, from 1 (explain the idea) to 6 (a worked example). Each lab sets a maximum. |
| **Lab** | A small project with a guide, starter code and tests, done in your own VS Code. |
| **Lab Forge** | The feature that writes a new lab on a topic you choose. The service writes it and DevPilot checks it on your computer before adding it. |
| **Learning path** | An ordered list of 3 to 8 steps for a goal, each with a lesson, videos, a quick check and a lab. |
| **Practice** | A result produced on your own computer. Labelled Practice wherever it appears. |
| **Protected tests** | Private tests that never ship in the app. |
| **Quick check** | Three questions at the end of a step's lesson. Two right passes. |
| **Roadmap** | A plan made of DevPilot's ready-made labs, in a good order. |
| **Session (lab session)** | The private connection between the helper and VS Code while a lab is open. |
| **Starter** | The files you begin a lab with. |
| **Step** | One unit of a path or a lab. |
| **Tutor** | The AI helper that gives hints, never the finished answer. |
| **Verified** | The credential level for work the DevPilot server checks itself. Planned, not available yet. |
| **Visible tests** | The tests shipped with a lab. You can read and run them. |
