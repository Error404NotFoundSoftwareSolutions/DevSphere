# Security policy

DevSphere takes security seriously. Please report vulnerabilities privately.

## How to report
Do **not** open a public issue. Contact the security owner listed in `.github/CODEOWNERS` (a dedicated security contact address and private advisory channel must be set up by the repository owner before the first public release; until then, report to the repository owner directly).

Please include: what you found, steps to reproduce, affected version, impact, and any proof of concept. Do not access other people's data or run destructive tests.

## What to expect
Acknowledgement within 3 business days, triage, a fix plan by severity (`docs/security/VULNERABILITY_MANAGEMENT.md`), and credit if you wish.

## Scope
The desktop app, bundled extensions, backend services, grader, content pipeline and release/update process. Out of scope: social engineering, physical attacks, third-party services we do not operate.

Full programme: `docs/security/README.md`.
