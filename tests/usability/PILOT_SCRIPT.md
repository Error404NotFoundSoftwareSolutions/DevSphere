# Pilot script (PL-01)

1. Welcome and consent (read the privacy notice aloud; students may stop at any time).
2. Task: install the app, sign in, complete `python-hello-001` without help. Note time and every point of confusion.
3. Observe silently. Intervene only if stuck for 5 minutes; record the intervention.
4. Short questions: what was unclear, did the tutor help, did the result feel fair?
5. Log each finding in `docs/USER_TESTING_LOG.md` with the change you made.
