## 0.1.0-preview.1 (2026-11-12): first public Linux preview

- **Platform:** Linux x64 only, as a `.tar.gz` folder with `install.sh`. No Windows or macOS build yet, no AppImage or
  `.deb`, no automatic updates. Published as a pre-release with SHA-256 checksums.
- **In it:** AI learning paths (Gemini on Google Cloud), measured video watching inside the app, guided labs that open in
  VS Code with the DevPilot Guide extension and are checked on your own computer, the tutor (hints, not answers), the
  interview coach, credentials, the light and dark design and the journey map.
- **Uses the hosted DevPilot service** for paths, videos, the tutor and the coach. Sign in with email or Google.
- **Not done for this preview** (from `docs/RELEASE_CHECKLIST.md`): signed installers, Windows and macOS builds, the
  update feed, clean-machine install tests on every OS.
